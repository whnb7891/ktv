# KTV Rhythm（轻量节奏点唱）

这是一个放在仓库 whnb7891/ktv 的简单响应式网页小项目，演示一个适用于手机、平板、和桌面的轻量节奏点击游戏原型。

特点：
- 纯前端 HTML/CSS/JS，无依赖。
- 响应式布局，支持触摸和键盘（空格/回车）。
- 简单判定与得分系统，可扩展为多轨/音乐/谱面系统。

如何运行：
1. 下载或克隆仓库。
2. 在浏览器中打开 `index.html`（或使用静态服务器如 `npx http-server`、`python -m http.server`）。
